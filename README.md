# ms-config-2026

## Configurações da Aula 9
Publique o conteúdo desta pasta na raiz de um repositório GitHub.
O arquivo application.properties é o padrão. A pasta config contém os perfis dev, qa, perf e prod.
As chaves usam o prefixo client2026ms, igual ao cliente Java.
Não inclua propriedades do próprio servidor ou spring.config.import nestes arquivos.
